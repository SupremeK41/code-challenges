# Code Challenges

My independent coding practice, kept separate from course projects, AI-assisted experiments and my dissertation.

## Folders

```text
leetcode/
  javascript/
  python/
coderbyte/
  practice/
    javascript/
    python/
sql/
  practice/
fundamentals/
  javascript/
  python/
templates/
```

One folder per problem contains an attempt, my explanation and actual checks. No problems are marked solved merely because the folder exists. The initial repository contains organisation/templates, not completed solutions.

## Start a problem

```text
python new_challenge.py leetcode two-sum --language javascript --url https://leetcode.com/problems/two-sum/
python new_challenge.py coderbyte array-practice --language python
python new_challenge.py sql joins-practice --language sql
```

The helper creates an empty attempt and notes. It does not supply a solution or mark progress. Link the public problem and summarise it in my own words instead of copying question text.

For each attempt, record:

1. My approach before coding.
2. The code I wrote and an explanation of why it works.
3. Edge cases and actual test results, including failed attempts.
4. Time/space complexity where relevant.
5. Documentation, hints, editor assistance or AI help used.
6. A later retry or unseen variation, when actually completed.

## Assessments

Coderbyte here means public practice. Employer assessments, private links, question text, answer keys, screenshots and assessment correspondence do not belong in this public repository. Keep those records in the private career workspace. Complete assessments personally under their rules.
